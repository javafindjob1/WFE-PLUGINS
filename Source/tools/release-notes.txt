War3DeathSettlement 发布包
==========================

版本：2.2.12
构建形式：单个 .NET 10 自包含 x64 桌面程序，WFE 使用单个 ddh.dll。

运行前置条件：
  - Microsoft Edge WebView2 Runtime

一、包内内容
------------
Desktop\War3DeathSettlement.exe
  桌面结算程序，已内嵌死亡结算、伤害事件和战场单位页面。
Desktop\hook\ddh.dll
Desktop\hook\ddh_inject.exe
  不依赖 WFE 的独立注入文件。

Game\WFE-Libraries\ddh.dll
  WFE 加载的单一伤害采集模块，只负责伤害钩子和 SQLite 落库。

二、游戏内行为
--------------
- 游戏内不显示任何结算按钮。
- 游戏内不显示结算页、覆盖层、阵亡总结或承伤图表。
- 不启动 ddh_web，不创建游戏内画面共享内存。
- 共享内存协议升级为 v36，只保留伤害事件环和单位属性块，总长 141256 字节。
- 单位死亡数据仍写入 SQLite，可在桌面程序里查看。

三、安装游戏内采集
------------------
1. 完全退出魔兽争霸和 WFE。
2. 双击 install_release.cmd；如果系统阻止，请右键以管理员身份运行。
3. 安装器会更新：
   C:\3rd\wc3gamesearcher\WFE\Application\Libraries\ddh.dll
4. 安装器会删除旧版 C:\launch\ddh_web、页面资源和游戏内启动脚本。
5. 重新启动 WFE，再启动魔兽并进入地图。

四、桌面版
----------
直接运行 Desktop\War3DeathSettlement.exe。
桌面版是 .NET 10 自包含单文件程序，无需另装 .NET；历史、日志和设置路径仍按程序配置
写入用户目录。

不依赖 WFE 独立运行：
1. 不使用 WFE，正常启动魔兽并进入地图。
2. 右键以管理员身份运行 Desktop\War3DeathSettlement.exe。
3. 程序会连接游戏，并使用 Desktop\hook\ddh_inject.exe 注入 Desktop\hook\ddh.dll。
4. 如果平台以管理员权限启动魔兽，桌面程序也必须以管理员身份运行。

五、当前界面要点
----------------
- 三个页签：死亡结算、伤害事件、战场单位。
- 每页结算 200 条，每页伤害事件 500 条。
- 伤害事件固定前三列：时间、触发单位、伤害来源。
- 筛选、分页、历史会话和诊断都只在桌面程序中操作。
- “地图伤害 > 0、净掉血 = 0”是允许的：伤害可能被同帧回血抵消。

六、校验
--------
SHA256SUMS.txt 包含包内所有文件的 SHA-256。
发布包不得包含 Game\ddh_web、dss.html、dss-assets 或 ddh_web_launcher。
